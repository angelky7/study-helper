# HydroGenius - 氢能科研智能助手

 一个专为氢能领域研究人员设计的智能工具平台

## 项目简介

HydroGenius 是面向氢能科学与工程专业学生及研究人员的智能科研助手，集成文献分析、实验数据处理、报告生成和专业知识问答四大核心功能。

## 功能特性

###  文献智能助手
- 输入研究方向，AI自动梳理研究脉络
- 展示领域研究趋势可视化
- 推荐热门研究方向和关键词

### 📊 实验数据分析
- 支持上传电解水实验CSV数据
- 自动生成电压-时间、产氢量-时间曲线
- 计算产氢速率、效率等关键参数
- 提供示例数据下载

### 📝 研究报告生成
- 结构化报告模板
- 一键生成Markdown格式报告
- 支持下载和分享

### 💬 氢能知识问答
- 内置氢能专业知识库
- 覆盖电解水、储氢、燃料电池等核心领域
- 智能匹配问题与答案

## 技术栈

- **前端框架**: Streamlit
- **数据处理**: Pandas, NumPy
- **数据可视化**: Matplotlib
- **文档生成**: Python-docx

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行应用

```bash
streamlit run app.py
```

### 3. 访问应用

打开浏览器访问 `http://localhost:8501`

## 使用示例

### 数据分析流程
1. 点击"数据分析"标签页
2. 下载示例数据或上传自己的CSV文件
3. 查看自动生成的可视化图表
4. 阅读数据分析结果

### 报告生成流程
1. 点击"报告生成"标签页
2. 填写研究信息（标题、作者、摘要等）
3. 点击"生成报告"
4. 预览并下载Markdown格式报告

## 适用场景

- 氢能相关课程的课程作业
- 电解水实验数据处理
- 研究文献快速调研
- 学术报告撰写辅助
