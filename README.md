# 学涯助手 - 大学生效率工具箱

> 选课不纠结 · 考试不慌张 · 时间不浪费

一个专为大学生设计的学习效率工具，集成考试倒计时、课程管理、任务规划和学习统计四大功能。

**在线体验：** https://study-helper-1rc7u9fb4xh.qoder.zone

## 功能特性

### 📅 考试倒计时
- 添加考试日期，自动计算剩余天数
- 按紧急程度分色显示（红/黄/绿）
- 根据剩余时间智能生成备考建议（冲刺/一周/两周/提前规划）

### 📋 课程管理
- 记录课程名称、老师、时间、地点、学分
- 自动统计总学分
- 快速查看全部课程安排

### ✅ 任务规划
- 支持作业、实验报告、预习复习、小组任务、论文等类型
- 按截止日期自动排序，逾期标红
- 显示预计总耗时，帮助评估工作量
- 一键标记完成

### 📊 学习统计
- 每日打卡学习时长和内容
- 柱状图展示学习趋势（Chart.js）
- 周目标进度条（默认 20 小时）
- 累计学习、日均时长、打卡天数一目了然

## 技术实现

| 层面 | 技术选择 |
|------|---------|
| 前端 | 纯 HTML + CSS + JavaScript，单文件部署 |
| 数据可视化 | Chart.js 柱状图 |
| 数据存储 | localStorage，无需后端，打开即用 |
| 部署 | Qoder Sites |
| 开发工具 | Qoder |

设计原则：**零依赖、零配置、打开就能用**。不需要注册账号，不需要安装 App，浏览器打开链接即可。数据存在浏览器本地，关掉不丢失。

## 本地运行

无需构建，直接用浏览器打开 `web/index.html` 即可；或启动任意静态服务器：

```bash
cd web
python -m http.server 8080
# 访问 http://localhost:8080
```
